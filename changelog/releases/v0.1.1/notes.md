This release publishes Pi Vim Editor to npm. It's identical to v0.1.0, which reached GitHub but not npm.

## 🐞 Bug fixes

### Publish to npm

Version 0.1.0 was released on GitHub but never reached npm, because npm had already seen that version number for the package name. This release publishes the same extension to npm, so `pi install npm:pi-vim-editor` installs it.
